4.Проект Игра в кости
Данный проект написан на языке программирования Python. Интересно, что несмотря на то, что это игра, она реализована исключительно основными базовыми средствами питона без  использования специальных библиотек. 
Ав коде есть два бота, один из них  математически рассчитывает наиболее вероятный исход броска кубика (бросок генерируется с использованием библиотеки рандома) и выводит свою цифру. Также есть бот, который выбирает рандомное число ( библиотека рандома). 
Помимо этого пользователь может делать ставки и у каждого из участников есть свой виртуальный банковский счёт. Игра продолжается до тех пор, пока каждый из игроков в состоянии внести минимальный размер ставки (указан в программе). В противном случае игра завершается и выводятся результаты.
